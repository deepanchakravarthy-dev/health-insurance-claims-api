# 🏥 Health Insurance Claims API

A backend application built using **Java**, **Spring Boot**, and **MySQL** to automate health insurance claim submissions, validations, and settlements. This project was developed as part of a real-time implementation at **Inventzo Systems (India) Pvt. Ltd.** for the client **Great American Insurance Group**.

---

## 🔧 Tech Stack

- **Java 8**
- **Spring Boot**
- **Spring MVC**
- **Hibernate / JPA**
- **RESTful APIs**
- **MySQL**
- **Maven**
- **JUnit**
- **Docker** (optional)
- **Jenkins** (CI/CD)
- **GitHub** for version control

---

## 🚀 Features

- ✅ Secure and scalable REST API endpoints for:
  - Claim submission and validation
  - Policy and patient management
  - Settlement tracking
- ✅ JWT-based Authentication (can be added)
- ✅ Integration-ready for healthcare and diagnostic APIs
- ✅ Database schema design and optimization using MySQL
- ✅ Unit & integration testing using JUnit
- ✅ Microservices architecture support
